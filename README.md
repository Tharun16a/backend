\# FuelEU Maritime — Backend Service  

A hexagonal-architecture backend implementing FuelEU Maritime regulation logic:  

\- Route management  

\- GHG comparison  

\- Compliance Balance (CB) engine  

\- Banking (Article 20)  

\- Pooling (Article 21)



Built for the \*\*FuelEU Maritime Full-Stack Developer Assignment\*\*.



---



\## 🚀 Tech Stack

\- Node.js + TypeScript  

\- Express  

\- In-memory storage (mock DB for assignment)  

\- Hexagonal Architecture (Ports \& Adapters)
